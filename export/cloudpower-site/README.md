# Cloud Power — site concept V2 (all pages)

Open `index.html` in a browser. All pages link to each other.

Pages: index (homepage), our-services, managed-services, ai, soc-as-a-service, consulting,
digital-conception, contact-us, news, and three articles (news-*.html).

- Each page is self-contained (CSS and JS inline); images are in `assets/`.
- Fonts (Geist, Geist Mono) load from Google Fonts, so an internet connection is needed for the exact typography.
- Desktop concept, designed at 1440 px. The contact form is a mockup and sends nothing.
- All text comes from cloud-power.eu. The grey "Review notes" block at the bottom of each page is for review only.
- The live website has not been modified.

## Block A — shared style (paste at the start of every page prompt)

```
Desktop web page, 1440 px wide, for Cloud Power Luxembourg (IT managed services). Same design system as the approved homepage:
- Colours: abyss #001A1E and teal #002F35 for dark sections, #07404A secondary dark, mint #EEFFFD text on dark, paper #F4FAF9 and mist #E2EEEC for light sections, slate #3E4042 body text, one accent cyan #12D3D8 (darker #077E83 on light backgrounds). - End every page with one dark closing band: large headline + one short line + a single "Contact Us" button. Then a slim footer: logo, links (Our Services, News, Contact Us, Linkedin), "© 2025 Cloud Power Luxembourg SA".
- Clean, spacious, editorial. Sharp corners, no rounded cards, no stock icons sets, no emojis. Only one call to action: Contact Us.
- Use only the text I give below. Do not invent statistics, clients, certifications, prices or extra services.
```
